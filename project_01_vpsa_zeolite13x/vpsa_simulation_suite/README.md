# VPSA Simulation Suite (Zeolite 13X)

Engineering evaluation suite, dynamic benchmark datasets, and model validation artifacts for Vacuum Pressure Swing Adsorption (VPSA) systems.

## Overview
This repository contains:
- **Model Validation**: Comparisons of experimental vs. simulated breakthrough curves for $CO_2/N_2$ separation on Zeolite 13X.
- **Process Benchmarks**: Cycle purity, recovery, specific productivity, and vacuum energy consumption metrics.
- **Public Core Interface**: Lightweight API contracts and simulation wrappers.

*Note: Core proprietary industrial multi-bed PDE/LDF solvers remain closed-source.*
