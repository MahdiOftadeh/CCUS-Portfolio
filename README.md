# CCUS-Portfolio
A computational research portfolio focused on CCUS optimization using Physics-Informed Machine Learning,Surrogate Modeling, and Bayesian Optimization.

## 🎯 Research Vision
This repository serves as a centralized hub for my computational research efforts in **Carbon Capture, Utilization, and Storage (CCUS)**. My work aims to bridge the gap between classical chemical engineering principles and advanced data-driven methodologies to accelerate the transition to sustainable energy systems.

## 🛠️ Core Methodologies
The projects within this portfolio leverage a synergistic approach of:
* **Physics-Informed Machine Learning (PIML):** Integrating thermodynamic and transport phenomena constraints into neural network architectures.
* **Surrogate Modeling:** Developing high-fidelity, low-cost computational models to replace expensive mechanistic simulations.
* **Bayesian Optimization:** Navigating complex, high-dimensional design spaces for optimal process configuration.

## 📂 Repository Structure
The repository is organized by specific research tasks:
- `projects/`: Contains individual research projects, each with its own codebase, data, and documentation.
- `core_library/`: (Optional) Shared modular code used across different CCUS optimization tasks.
